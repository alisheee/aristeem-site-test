Questions before you start

Do I need to install anything?

No. Your workspace opens in the browser. Programs are already running on the Windows side.

Will it work on my Mac?

Yes. Windows programs run in the workspace, so your macOS version does not matter. The same goes for iPad, Chromebook and Linux.

Where are my files?

In A-Storage, your personal project storage in the workspace. Files stay there after you close the browser.

Do I need a license for my program?

Where the vendor requires it, use your own license. Aristeem gives you the Windows workspace to run it in.
